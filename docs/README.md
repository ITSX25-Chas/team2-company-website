## Rutin

- GitHub Issues används för det dagliga arbetet.
- Backlogfilen ger utbildaren och gruppen en samlad översikt.
- Status sätts till `Done` först efter merge och verifiering.
- Säkerhetsfynd dokumenteras defensivt utan fungerande angreppsinstruktioner,
  hemligheter eller skarpa flaggvärden.
